# ☕ Data Structures & Algorithms in Java

Welcome to the **DSA in Java** repository!  
This repository contains topic-wise implementations of **Data Structures and Algorithms using Java**, created for interview preparation, competitive programming, and improving problem-solving skills.

It is helpful for:
- Placement preparation
- Coding interviews
- Competitive programming
- Learning core DSA concepts in Java

---

## 📚 Topics Covered

- Arrays
- Strings
- Searching & Sorting
- Recursion & Backtracking
- Linked List
- Stack & Queue
- Trees & Binary Trees
- Binary Search Tree
- Heap & Priority Queue
- Graphs
- Dynamic Programming
- Greedy Algorithms
- Sliding Window
- Bit Manipulation
- Java Collections Framework
